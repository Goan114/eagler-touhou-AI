# 妖妖梦本地 AI 合作

与红魔乡试玩版使用同一个避弹核心：P1 真人、P2 AI，沿用作品已有的多人伤害、掉落、独立资源、队友保护及赠残规则。网络传输关闭，不修改上游源码目录。

## 构建与入口

```sh
npm run build:th07 -- --source=/path/to/eagler-touhou --assets=/path/to/TH07 --emsdk=/path/to/emsdk --unifont=/path/to/unifont.otf
npm start
```

打开 `http://127.0.0.1:8144/th07.html`。正常选择难度、机体或 Practice，真人控制 P1，AI 使用另一位角色的 A 装备。五档实力、跟随／分别压制、收点、输出站位、主动放雷、动作持续时间、输入延迟和高级滑条与红魔乡版相同，默认“强强”。跟随使用队友 0.3 秒前的位置；无法跟随时恢复自主作战，有残机时可通过原有点按低速手势救援待救玩家。

需要包含 `ports/th07` 和 `common` 的 Eagler 源码，当前接入参考 Ritosa 主仓库 `115dc49d805781e88a8e8e2213fc9ad364ed73b5`。构建使用 CMake、Ninja、Emscripten，支持 `--cmake`、`--ninja`、`--jobs`、`--font` 和 `--thprac=off`。SDL、SDL_image、SDL_ttf 与 FreeType 使用构建器中的固定提交，缓存到 `build/deps`。

资源目录需要自己的 `th07.dat`；Windows 默认读取系统 `msgothic.ttc`，也可通过 `--font` 指定。默认包含 THPrac，需要 `--unifont` 或 `EAGLER_DEVELOPMENT_UNICODE_FONT`。当前与红魔乡试玩版相同，不打包背景音乐。

源文件复制到 `build/th07/source` 后才注入 AI，开启多人玩法、关闭网络传输。资源、字体和编译产物只放在忽略目录 `build/th07`、`web/th07-runtime`，不提交到 Git。构建不会启动游戏或运行测试。

## 结界处理

妖妖梦的 `invulnerabilityTimer` 同时承担结界倒计时。适配器明确区分以下情况：

- `BORDER_READY`、正在结界、结界释放后的短暂保护：搜索无敌帧数为 **0**，继续检查敌弹、激光和敌机接触，不把结界当成可撞弹的无敌。
- 结界期间仍会移动、跟随、射击、收点、救援，不停止 AI。
- 结界准备／生效／释放保护期间取消自动 Bomb 及排队的 X，避免将保命雷变成主动释放结界。
- 真正的重生无敌与队友 Bomb 保护继续读取保证有效的剩余时间；不修改游戏实际保护、结界和碰撞规则。

高级状态显示“结界相关保护”与实际交给搜索器的无敌帧数，分别对应 `th07_ai_metric(30/31)`。若结界发生在输入采集之后，本帧后续游戏状态仍由原核心处理，AI 下一逻辑帧重新读取。

## 控制、练习与存档

方向键、Z、Shift、X、Esc 控制真人。AI 开关按钮只影响 P2；保留 THPrac 原有 F8／Tab 统计快捷键，避免像红魔乡接入那样同时用 F8 切换 AI。

THPrac 从 Practice 进入，F12 打开高级选项、Backspace 打开功能菜单。菜单占用输入时暂停 AI，离开后重新规划。练习开始／Retry 后把最终配置的 P1 残机、雷、灵力同步给 AI，并更新录像开局资源快照；普通跨关保留各自资源。

本地双人输入由共用输入层提交，ReplayManager 不再覆盖 P2 或重复推进上一帧按键，并记录真实提交的双人按键。播放录像和演示时停止 AI，使用原来的录像输入。Extra／Phantasm 仍使用原容器的第七个录像槽。

内层页面固定挂载 `/savesth07-multiplayer`，保存到浏览器 IndexedDB，与单人目录分开。不要把这里的存档当作原版 Windows 游戏存档目录。

## 碰撞采集与限制

适配器读取实际机体的高速／低速速度、Bomb 移速、碰撞框和移动边界；读取正常敌弹的位置、已缩放速度和碰撞尺寸，近似持续加速／角加速；激光按剩余生效计时、长度与宽度逐帧生成旋转矩形，保留原作预警／消退阶段的长度赋值行为。敌机本体及已有的接触轨迹节点也纳入危险物。候选道具只取下半屏、未自动吸附的普通掉落。

仍不预测未来 ECL 出弹、出生动画结束时刻、反弹及任意脚本转向；角加速使用短窗口近似，每逻辑帧从真实状态重算。目标是复用现有轻量 AI，而非完整模拟未来游戏。不会推进游戏、读取未来 RNG 或修改生命、位置、得分。危险物容量、查询预算和完成度显示与红魔乡相同，核心算法和预设权重没有改动。
